# TEKNOFEST proje kurallari

- Once repo ve veri klasorlerini analiz et, hemen kod yazmaya baslama.
- Once calisan iskeleti kur, sonra optimizasyon yap.
- Kare bazli online pipeline varsay.
- JSON formatini bozan hicbir degisiklik yapma.
- Bu repo Task 3 odaklidir; Task 1 ve Task 2 baska repo'larda gelistirilir.
- 8 GB VRAM sinirini asma.
- Dynamic/conditional loading varsayilan strateji olsun.
- Hata durumunda gecerli fallback ve log uret.
- Her faz sonunda kisa rapor ver:
  1. Ne yaptin?
  2. Hangi varsayimlari yaptin?
  3. Hangi riskleri buldun?
  4. Hangi dosyalari ekledin/degistirdin?
  5. Sonraki adim ne?
